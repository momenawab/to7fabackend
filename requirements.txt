# Phase 4 (Part 4, production ASGI server): this project has used Channels
# (ASGI_APPLICATION, CHANNEL_LAYERS) since before this phase, but no ASGI server
# capable of actually running it in production was ever declared - `manage.py
# runserver` is WSGI/dev-only and support/consumers.py's WebSocket route would have
# no real server to run under. Daphne is the reference ASGI server maintained by the
# Django Channels project itself (same maintainers as `channels`/`channels-redis`
# above), so it's the natural choice over introducing a second, differently-maintained
# stack (e.g. uvicorn+gunicorn) for a single-process deployment - one server, not
# competing options. See PRODUCTION_READINESS.md for the actual run command.
